# Arquitectura

## Componentes

### last30days-skill

Motor externo de descubrimiento. Se mantiene separado y se integra mediante un adaptador.

### Inlak'ech Radar

Aplicación propia que:

- normaliza resultados;
- evita duplicados;
- calcula afinidad;
- explica evidencias;
- facilita revisión humana;
- genera candidatos;
- conecta con Relaticle.

### Relaticle

CRM externo para:

- personas;
- oportunidades;
- tareas;
- notas;
- seguimiento comercial.

## Principio operativo

El sistema no contacta ni publica automáticamente. Toda intervención requiere revisión humana.
